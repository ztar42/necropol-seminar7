# Серия промтов для этапа 3 «Даты» — вариант для Claude Haiku

Haiku — небольшая быстрая модель. Она хорошо выполняет короткие, точно описанные шаги
и хуже — открытые задачи («проанализируй искажения сам»). Поэтому по сравнению
с основной серией (для большой модели):

- шагов больше, каждый меняет одну вещь;
- всё, что можно дать готовым, дано готовым: варианты OCR-искажений, имена функций, формат вывода;
- в каждый промт встроены тесты (`assert`) с ожидаемыми ответами — это механизм контроля,
  который модель запускает сама и по которому видно, выполнен ли шаг;
- в конце каждого шага — команда запуска и требование показать вывод.

Промты подаются в один диалог по очереди. Перед первым промтом в папке должны лежать
`output/entries.csv` (результат этапа 1) и `code/evaluate.py` + `data/gold_dates.csv`.

## Промт 1 · каркас, формат, первые тесты

```text
Ты пишешь код на Python 3.10. Можно использовать только стандартную библиотеку (csv, re, pathlib).
Не используй pandas и другие сторонние пакеты.

ЗАДАЧА. Есть OCR-текст справочника «Петербургский некрополь» (1912, дореформенная орфография).
Файл output/entries.csv (кодировка utf-8-sig), столбцы: id, surname, is_reference, text.
Одна строка — одна статья о человеке. Пример text:
  Абаза, Аггей Васильевичъ, р. 16 декабря 1782 { 21 марта 1852 (Александро-Невская лавра).
«р.» — дата рождения. Знак «†» перед датой — дата смерти (в OCR он часто стал «+», «{», «|», «1», «Т»).

Создай файл code/dates_haiku.py. В нём:
1. Функция extract(text) -> dict с ключами "birth" и "death".
   Дата в формате "ГГГГ-ММ-ДД"; если день неизвестен — "ГГГГ-ММ"; если известен только год — "ГГГГ";
   если даты нет — "".
2. Функция main(): читает output/entries.csv, для каждой строки вызывает extract(text)
   и пишет output/dates_haiku.csv со столбцами id, birth, death (кодировка utf-8-sig).
3. Функция self_test() с проверками ниже. Запуск: python3 code/dates_haiku.py
   сначала вызывает self_test(), потом main(), и печатает, сколько статей получили дату смерти.

На этом шаге достаточно распознавать правильные названия месяцев:
января февраля марта апрѣля мая іюня іюля августа сентября октября ноября декабря
и знак смерти «+» или «†».

ПРОВЕРКИ (вставь в self_test как assert):
assert extract("Баженовъ, Иванъ Прокофьевичъ, р. 8 ноября 1791 + 8 января 1872 (Смоленское кладбище).") == {"birth": "1791-11-08", "death": "1872-01-08"}
assert extract("Боголюбовъ, Павелъ Николаевичъ + 28 декабря 1904 (Новодѣвичій монастырь).") == {"birth": "", "death": "1904-12-28"}
assert extract("Аксенова, Елизавета Ивановна—см. Анцъ.") == {"birth": "", "death": ""}

Выведи файл целиком. Затем запусти его и покажи вывод.
```

## Промт 2 · искажения OCR в месяцах

```text
Дата смерти находится только примерно у трети статей: в OCR-тексте месяцы искажены.
Замени распознавание месяцев на словарь шаблонов. Используй ровно эти шаблоны регулярных
выражений (номер месяца: шаблон), сравнение без учёта регистра (re.I):

1: ян\S?[ая]ря
2: ф?февраля
3: марта
4: апр\S{0,3}ля          (апрЪля, апрфля, апр$ля, апръфля)
5: мая
6: [1!|{(тпшгнШТІі'№‘]?[юо]{0,2}ня     (юня, поня, 1юня, пюня, шоня, ня)
7: [1!|{(тпшгнШТІі'№‘]?[юо]{0,2}ля     (юля, поля, 1юля, тюля, оля)
8: а[вз]\S?уста
9: сен\S?тября
10: о[кя]\S?тября
11: но\S?я\S?бря|нояря
12: дек?абря

Сделай функцию norm_month(word) -> номер месяца или None, которая проверяет слово по этим шаблонам
через re.fullmatch. Больше ничего в файле не меняй.

Добавь в self_test:
assert extract("Годенъ, Викторія + 28 поня 1905 (Католическое кладбище).")["death"] == "1905-06-28"
assert extract("Глазовъ, Петръ Ивановичъ + 19 1юля 1903, на 61 г. (Волково кладбище).")["death"] == "1903-07-19"
assert extract("Брезинская, Юстина + 16 апрфля 1889 (Смоленское кладбище).")["death"] == "1889-04-16"
assert extract("Волкова, Марія Филипповна + 2 Февраля 1894 (Новодѣвичій монастырь).")["death"] == "1894-02-02"

Выведи файл целиком, запусти и покажи вывод (все проверки должны пройти).
```

## Промт 3 · знак смерти, годы и дни с ошибками OCR

```text
Теперь знак смерти. В OCR «†» выглядит как один из символов: + † { | Т т ф — -
(иногда два подряд, например «+1» или «{|»). Правила:
- знак не может стоять внутри слова (буква «т» в слове «октября» — не знак);
- одиночная цифра «1» — знак смерти, только если после неё пробел: «1 5 марта» = † 5 марта,
  а «15 марта» — просто 15 марта.
Регулярное выражение для знака используй такое:
(?<!\w)(?:[+†{|Ттф—\-]{1,2}(?=[\s\d])|1(?=\s))

Ошибки OCR в числах исправляй отдельными функциями:
- norm_year(s): буква «т» -> 1, «з» -> 3; год от 1300 до 1399 -> прибавь 500 (OCR путает 8 и 3:
  «1336» = 1836); если в году есть точка («17..») -> None.
- norm_day(s): «т», «|», «l» -> 1; из «15/27» бери первое число; если получилось больше 31
  и начинается с 1 («115») — отбрось первую единицу; день вне 1–31 -> None.

Дата может быть и без дня и месяца — только год: «р. 1852 Т 1892».
Дата рождения ищется после «р.»; дата смерти — после знака и после даты рождения.

Добавь в self_test:
assert extract("Гребне, Софія-Доротея, р. 12 марта 1816 1 26 января 1877 (Волково кладбище).") == {"birth": "1816-03-12", "death": "1877-01-26"}
assert extract("Гюне, баронъ Эдуардъ, р. 15 ноября 1852 1 5 марта 1856 (Волково кладбище).") == {"birth": "1852-11-15", "death": "1856-03-05"}
assert extract("Гельмгольцъ, Ѳедоръ, капитанъ, р. 1852 Т 1892 (Гатчинское кладбище).") == {"birth": "1852", "death": "1892"}
assert extract("Алексѣевъ, Сергѣй, р. 4 юля 1805 Т 10 ноября 1853 (Волково кладбище).") == {"birth": "1805-07-04", "death": "1853-11-10"}
assert extract("Гамельманъ, Амалія, р. 9 февраля 1800 + 23 января 1336 (Волково кладбище).")["death"] == "1836-01-23"
assert extract("Гюльпенъ, Францискъ, р. 16 ноября 1818 т 3 ноября 1863 (Католическое кладбище).")["death"] == "1863-11-03"

Выведи файл целиком, запусти и покажи вывод.
```

## Промт 4 · «своя» часть статьи и слова между знаком и датой

```text
Две проблемы.

А) После основного человека в статье идут родственники со своими датами, например
«…+ 26 марта 1885. Жена: Вѣра Петровна + 23 октября 1909 (Смоленское кладбище)».
Ищи даты только в «своей» части: от первой запятой (после фамилии) до первого из:
- скобки «(» или «{» + заглавная буква, если в ближайших 80 символах до «)» есть одно из слов:
  кладбищ, лавр, монастыр, пустын, собор, церк, сел;
- слов: Жена, Мужъ, Дочь, Сынъ, Внучка, Надпись;
- «Съ » + заглавная буква («Съ М. И. Аксеновой»).
Скобка без этих слов («рожд. Дюлу (Бивоча)») — НЕ граница.

Б) Между «р.» или знаком смерти и датой могут стоять одно-два слова: «р. въ Ригѣ 9 апрѣля 1829»,
«+ убитъ 12 октября 1877», «+ въ Дрезденѣ 1833». Разреши до двух таких слов
(слово не должно начинаться с цифры или со знака смерти).
«рожд.» обычно значит «урождённая» (рожд. Соймонова) — дату после «рожд.» считай рождением,
только если она идёт сразу, без слов между ними.

Добавь в self_test:
assert extract("Акорчевъ, Александръ, колл. сов. { 26 марта 1885, на 61 г. Жена: Вѣра Петровна 1 23 октября 1909 (Смоленское кладбище).")["death"] == "1885-03-26"
assert extract("Банье, Андрей-Фридрихъ, р. въ Мекленбургъ-Шверинѣ 29 сентября 1769 + 27 апрѣля 1840, 70 л. (Волково кладбище).") == {"birth": "1769-09-29", "death": "1840-04-27"}
assert extract("Брюнъ-де-Сентъ-Ипполитъ, Елизавета, рожд. Дюлу (Бивоча) 1 5 февраля 1843, 34 л. (Смоленское кладбище).")["death"] == "1843-02-05"
assert extract("Годенъ, Викторія, рожд. Вердье + 28 поня 1905, 71 г. (Католическое кладбище).")["birth"] == ""
assert extract("Вальдманъ, Елена, рожд. Шинна, р. въ Митавѣ 30 сентября 1799 т 1 мая 1875 (Гатчинское кладбище).") == {"birth": "1799-09-30", "death": "1875-05-01"}

Выведи файл целиком, запусти и покажи вывод.
```

## Промт 5 · механизм контроля

```text
Добавь механизм контроля. Для каждой статьи считай список флагов (столбец flags в dates_haiku.csv,
флаги через «;»):
- birth_year_out_of_range / death_year_out_of_range — год не между 1700 и 1912;
- birth_after_death — год рождения больше года смерти;
- age_over_110 — разница годов больше 110;
- year_present_but_no_death — в «своей» части есть четырёхзначный год 16xx–19xx, а дата смерти не найдена.

Статьи с флагами запиши в output/dates_haiku_review.csv (id, birth, death, flags, text).
В конце main() напечатай сводку: число статей без отсылок (is_reference = 0),
сколько из них с датой смерти и с датой рождения (число и процент), сколько каждого флага.

Добавь в self_test:
r = extract("Аркъ-фанъ, Карлъ, р. 28 августа 1839 + 11 августа 1992 (Волково кладбище).")
assert "death_year_out_of_range" in r["flags"] and "age_over_110" in r["flags"]

Выведи файл целиком, запусти и покажи вывод.
```
